# 📂 Antecedentes y Reuniones - Grúas San Pablo (GSP)

Este directorio está destinado a almacenar toda la documentación de soporte, actas de reuniones, decisiones de diseño y antecedentes del proyecto.

## 🗂️ Estructura del Directorio

*   [antecedentes/](file:///d:/SGajardo/Google%20Drive/Antigravity/Grúas%20San%20Pablo/Propuesta%20Gestión%20Operación%20Grúas/antecedentes_reuniones/antecedentes/README.md): Documentos técnicos de referencia, diagramas conceptuales, manuales o archivos compartidos por el cliente.
*   [reuniones/](file:///d:/SGajardo/Google%20Drive/Antigravity/Grúas%20San%20Pablo/Propuesta%20Gestión%20Operación%20Grúas/antecedentes_reuniones/reuniones/README.md): Minutas y bitácora de reuniones de alineación técnica y de negocio.

## 📝 Uso Recomendado

1. **Reuniones:** Cada vez que se realice una reunión, se debe crear un nuevo archivo Markdown en `reuniones/` con el formato `YYYY-MM-DD_reunion_descripcion.md` utilizando la [Plantilla de Minuta](file:///d:/SGajardo/Google%20Drive/Antigravity/Grúas%20San%20Pablo/Propuesta%20Gestión%20Operación%20Grúas/antecedentes_reuniones/reuniones/YYYY-MM-DD_plantilla_minuta.md).
2. **Antecedentes:** Agregar los documentos o descripciones de flujos existentes en `antecedentes/` para que los agentes de IA puedan consultarlos como fuente de verdad.
